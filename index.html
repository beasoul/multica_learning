Multica 精读课：从看懂到改得动

14 课，一条从"它是什么"走到"我能改它"的路线。每课一个主题、一次检索练习，全部结论都能在 C:\coding\multica 源码里找到出处。所有文件本地可打开，无需联网。

14 课 8 张设计图 5 份速查文档 面向：Oracle + Python 背景

这门课为谁写

写给一个想驾驭 Multica 而不是只会点界面的人。目标定义在 MISSION.md，教学偏好与这台机器的环境坑记在 NOTES.md，所有引用来源清单在 RESOURCES.md。

学习方式

一次只吃一个主题，30-40 分钟一课。每课末尾都有需要回忆才能作答的题——不要"读一遍就往下翻"，答案自己写出来才算学会。

建议顺序：0001 → 0014 顺着走。前 6 课建立主干（领域模型与 Run 链路），7-9 课是执行与实时，10-13 课按你的兴趣挑顺序，0014 收口做排查与实战。

课程目录

  1. 01 先看清全貌：它到底解决了什么问题 名字由来、它不做什么、三层分工、授权模式。配图 01。
  2. 02 领域模型：先把八个名词钉死 Workspace / Issue / Run / Agent / Runtime / Squad / Skill / Autopilot。三个最容易搞错的地方。
  3. 03 仓库分层：为什么文件不能随便放 core / ui / views 的硬边界；Go 的 cmd / internal / pkg 三分。配图 02。
  4. 04 一个 HTTP 请求的旅行：从路由到 SQL 全局中间件链、三组路由、handler → service → sqlc。附"3 分钟定位任意接口"套路。
  5. 05 Run 的状态机：八个状态，一条主线 deferred / queued / dispatched / waiting_local_directory / running / 三个终态。配图 03。
  6. 06 一次 Run 的端到端时序与凭据链 四种令牌如何逐级收窄；注入给 Agent 的环境变量。配图 04。
  7. 07 daemon：那台真正跑活的机器 启动序列、推 + 拉双保险、claim 的原子性、看门狗与 GC。配图 05。
  8. 08 CLI 与 daemon：一个二进制，两副面孔 profile 隔离、工作区解析优先级、脚本化实战、退出码分层。
  9. 09 实时同步：两条 WebSocket 通道 人类通道 vs daemon 通道、事件粒度、前端 patch 与 invalidate。配图 06。
  10. 10 数据库与迁移：用 Oracle 的眼睛读 PostgreSQL 三条硬规则、CONCURRENTLY、表达式索引与统计信息、检索策略演进。
  11. 11 权限与安全：把三层边界分清 认证 / 授权 / 执行隔离；官方对"不做沙箱"的完整说明。配图 08。
  12. 12 跑起来：自部署与本地开发两条路 make selfhost 与 make setup/start/check/down；worktree 隔离；健康检查。配图 07。
  13. 13 集成与插件：让 Multica 长出去 集成 vs 插件；Action / Hook / Resource 三种关系；封闭的 scope 清单。
  14. 14 收官：分诊故障，然后动手改一处 按"Run 停在哪个状态"分诊；三个梯度的改动方案；改代码的五条规矩。
