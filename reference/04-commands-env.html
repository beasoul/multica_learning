Reference 04

命令与环境变量

写脚本、调 daemon 参数时查这一页。命令来自 CLI_AND_DAEMON.md 与 Makefile；环境变量默认值来自 internal/daemon/config.go。

约 8 分钟对应课程：0008、0012

起步三条

multica setup              # 一条命令：写配置 + 浏览器登录 + 起 daemon（连官方云）
multica setup self-host    # 连自部署
multica daemon status      # 确认检测到哪些 Agent、监听哪些工作区

daemon 操作

命令用途
multica daemon start后台起；--foreground 前台跑（看启动过程）
multica daemon stop / restart停 / 重启（重启会释放内存态的目录互斥）
multica daemon status --output json机器可读状态
multica daemon logs -f · -n 100 · --profile <name>看日志；每次都先打印它解析到的绝对路径
multica daemon disk-usage磁盘占用（.repos 单独一行）

认证 / 配置

命令用途
multica login浏览器 OAuth，生成 90 天 PAT，自动加入你所属工作区
multica login --token <mul_...>无头环境；--token= 交互输入（不进 shell 历史）
multica auth status / auth logout查当前服务端、用户、令牌有效性 / 清除令牌
multica config show看配置文件路径、server_url、app_url、默认工作区
multica config set server_url <url>改服务端地址
multica workspace switch <id|slug>切换默认工作区（会先校验可访问）

工作区解析优先级（高到低）：--workspace-id → MULTICA_WORKSPACE_ID → 当前 profile 保存的默认值。脚本里用前两个。

Issue / Run 日常

multica issue list --status todo --assignee "Lambda" --output json
multica issue create --title "..." --priority high --assignee "Lambda"
multica issue assign <id> --to "Lambda"        # 或 --to-id <uuid> / --unassign
multica issue status <id> in_progress
multica issue reorder <id> --top                # --bottom / --before / --after

multica issue runs <id>                         # 全部执行记录
multica issue runs <id> --active --output json  # 只看在途的
multica issue run-messages <task-id> --since 42 # 单次运行的详细消息流
multica issue usage <id> --output json          # 聚合 token 用量

内建状态：backlog · todo · in_progress · in_review · done · blocked · cancelled（工作区可加自定义状态）。

Autopilot 与其它

multica autopilot list --status active --output json
multica autopilot trigger <id>                  # 手动触发一次（未真正启动则非零退出）
multica autopilot trigger-add <id> --cron "0 9 * * 1-5" --timezone "Asia/Shanghai"
multica autopilot trigger-add <id> --kind webhook
multica autopilot runs <id> --limit 50 --output json

multica agent list                              # 当前工作区的 Agent
multica project create --title "..." --lead "Lambda"
multica version · multica update

脚本友好性

能力用法
JSON 输出--output json
字段裁剪（仅 JSON）--fields=id,title,status,priority
退出码0 成功 · 1 未分类 · 2 网络 · 3 认证/授权 · 4 未找到 · 5 校验
完整错误链--debug 或 MULTICA_DEBUG=1
请求超时MULTICA_HTTP_TIMEOUT=60s（默认 30 秒；接受 45s 或 45）
技能下载无进展超时MULTICA_HTTP_STALL_TIMEOUT=45s（默认 15 秒无字节即失败，整体上限 10 分钟）
中文报错检测到 LC_ALL / LC_MESSAGES / LANG 为中文即切换，无需参数

daemon 环境变量

变量默认说明
MULTICA_SERVER_URLws://localhost:8080/ws服务端地址
MULTICA_DAEMON_POLL_INTERVAL30s轮询兜底（WebSocket 唤醒会更快）
MULTICA_DAEMON_WS_CLAIM_POLL_INTERVAL3mWebSocket 健康时的领取轮询上限（含向下抖动）
MULTICA_DAEMON_HEARTBEAT_INTERVAL15s心跳
MULTICA_DAEMON_MAX_CONCURRENT_TASKS20单 daemon 并发上限
MULTICA_DAEMON_ID主机名守护进程标识
MULTICA_DAEMON_DEVICE_NAME主机名设备显示名
MULTICA_AGENT_RUNTIME_NAMELocal AgentRuntime 显示名
MULTICA_WORKSPACES_ROOT~/multica_workspaces本机工作目录根
MULTICA_KEEP_ENV_AFTER_TASK—设 true/1 则任务结束后保留环境目录

看门狗与超时

变量默认
MULTICA_AGENT_TIMEOUT0（不限）
MULTICA_AGENT_IDLE_WATCHDOG2h（0 关闭整套看门狗）
MULTICA_AGENT_TOOL_WATCHDOG同 idle（0 = 工具调用中永不强停）
MULTICA_OPENCODE_IDLE_WATCHDOG10m
MULTICA_CODEX_SEMANTIC_INACTIVITY_TIMEOUT同 idle
MULTICA_CODEX_HANDSHAKE_TIMEOUT30s（thread/start 与 thread/resume 为 60s）
MULTICA_CODEX_TURN_INTERRUPT_TIMEOUT2s
MULTICA_CODEX_FIRST_TURN_TIMEOUT0（保留内建 60s 上限）

垃圾回收

变量默认
MULTICA_GC_ENABLEDtrue
MULTICA_GC_INTERVAL2h
MULTICA_GC_TTL（issue 已 done/cancelled）24h
MULTICA_GC_COMPLETED_TASK_TTL云 14d；自部署 0（禁用）
MULTICA_GC_ORPHAN_TTL72h
MULTICA_GC_ARTIFACT_TTL12h（0 禁用）
MULTICA_GC_ARTIFACT_PATTERNSnode_modules,.next,.turbo（仅匹配目录名，.git 内不下探）
MULTICA_GC_REPO_TTL720h（30d）
MULTICA_GC_REPO_MAINTENANCE_ENABLEDtrue（false 只关重型 Git 维护）
MULTICA_GC_HERMES_MEMORY_TTL2160h（90d）
MULTICA_GC_HERMES_SESSION_TTL336h（14d）
MULTICA_GC_TASK_TEMP_LEGACY_TTL0（禁用；只有在确认没有旧版 daemon 在跑时才设值）

自更新与重载

变量默认说明
MULTICA_DAEMON_AUTO_UPDATE官方云为开，自部署默认关向 GitHub Releases 查新版
MULTICA_DAEMON_AUTO_UPDATE_INTERVAL6h检查间隔
MULTICA_DAEMON_AUTO_RELOADtrue（桌面端管理的 daemon 忽略）跟随"被替换的二进制"重启（等当前任务结束）
MULTICA_RELEASE_API_BASE_URL—自部署的 release 元数据镜像
MULTICA_RELEASE_DOWNLOAD_BASE_URL—自部署的构件镜像

Makefile 目标

目标做什么
make help列出全部目标与说明（就是本文档的命令来源）
make selfhost / selfhost-build / selfhost-stop自部署栈：用官方镜像 / 从当前 checkout 构建 / 停止
make setup装依赖、确保数据库、跑迁移
make start / stop起 / 停当前 checkout 的后端与前端
make status / list看当前环境 / 列出机器上所有开发环境
make down / destroy停但保留数据 / 删库删 profile 释放槽位
make gc回收目录已消失或 TTL 过期的环境
make checktypecheck + TS 测试 + Go 测试 + Playwright E2E
make db-up / db-down / db-reset / db-drop共享 PostgreSQL 容器与当前环境数据库操作
make worktree-env为 worktree 生成唯一库名与端口的 .env.worktree
make api-dev / web-dev / desktop-dev只起其中一部分
make env-exec ARGS="-- ..."用本环境的变量跑任意命令
make sqlc改 SQL 后重新生成

本机工作目录布局

~/.multica/                       # 默认 profile 的状态目录
├─ daemon.log                     # 日志
├─ daemon.err.log                 # 启动/崩溃输出
├─ daemon.pid                     # 后台进程 PID
└─ profiles/<name>/               # 命名 profile 的同名文件 + 独立配置/端口/工作区根

~/multica_workspaces/             # 各任务的隔离工作目录（可由 MULTICA_WORKSPACES_ROOT 改）
