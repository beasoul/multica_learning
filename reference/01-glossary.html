Reference 01

术语表

按字母序排列。每条只给一句话定义 + 一个源码出处，不展开——展开在对应课程里。

约 5 分钟对应课程：0002 为主

A–F

术语一句话定义出处
Agent 智能体一份配置（provider、系统提示、Skill），不是进程。可被指派为 assignee。internal/agentconfig/；agents.zh.mdx
Agent CLI本机已装好并登录的编码工具（claude、codex 等 26 种），真正干活的那个。scripts/agent-cli-command-names.txt
Action插件契约的一种关系：插件调用宿主能力，受 scope 限制。pkg/plugincontract/manifest.go
assignee 被指派人多态字段：assignee_id 必须配 assignee_type 才能区分人 / Agent / Squad。AGENTS.md · Backend UUID Rules
Autopilot 自动驾驶定时（cron）或 webhook 触发的自动化，按 create_issue 或 run_only 模式派活。service/autopilot.go；autopilots.zh.mdx
claim 认领daemon 原子抢到一条 queued 的 Run，服务端同时签发运行令牌。防重复执行。handler/daemon.go；POST /api/daemon/tasks/claim
Composio第三方 SaaS 桥接集成，把外部工具接成 Agent 可用能力。internal/integrations/composio/
daemon 守护进程跑在你机器上的常驻进程，与 multica CLI 同一个二进制。负责登记能力、领取 Run、spawn CLI。internal/daemon/；CLI_AND_DAEMON.md
deferredRun 状态：已建但未到 fire_at，完全不动。定时唤醒任务的落点。pkg/db/queries/agent.sql
dispatchedRun 状态：已被某 daemon 认领、凭据已签发，但 CLI 还没起。pkg/protocol/events.go

H–R

术语一句话定义出处
Hook插件契约的一种关系：宿主调用插件能力。声明一次，可被它 opt-in 的任一触发器调用。pkg/plugincontract/manifest.go
Inbox 收件箱需要你处理的流：Agent 交回评审、被 @、Run 失败。packages/core/inbox/；queries/inbox.sql
Issue 任务单人的工作单元。与 Run 是 1:N：一张单子可能被反复执行。queries/issue.sql；issues.zh.mdx
mat_运行令牌：mat_ + 40 位十六进制，绑定 (agent_id, task_id)，单用途。internal/auth/jwt.go
mdt_daemon 令牌：mdt_ + 40 位十六进制，只能进 /api/daemon/*。internal/auth/jwt.go
mul_个人访问令牌 PAT：mul_ + 40 位十六进制，权限与你的会话等同。internal/auth/jwt.go
Multica LicenseApache 2.0 全文 + 附加条件（托管服务、商业嵌入、品牌三方面）。LICENSE · NOTICE
Project 项目代码仓库绑定与本地目录规则。决定 daemon 把哪个目录交给 Agent。queries/project.sql；project-resources
queuedRun 状态：在队列里等一个能干的 Runtime 认领。pkg/protocol/events.go
Resource插件契约的一种关系：不产生任何调用，纯静态贡献（如 Skill 文本）。pkg/plugincontract/manifest.go
Run 执行一次"让某个 Agent 去做这个 Issue"的尝试。代码里叫 task，表名 agent_task_queue。service/task.go
Runtime 运行时某台机器上、某个 provider 的一次实际可用安装。由 daemon 扫描注册，会掉线。queries/runtime.sql

S–Z

术语一句话定义出处
scope插件能调的宿主能力，封闭清单：issues/comments/tasks 的读写、agents:read、members:read、storage:*、net:<domain>。pkg/plugincontract/manifest.go
Skill 技能可复用的提示词 / 流程包，派给 Agent 或 Squad，运行时注入到 CLI。internal/skill/；skills.zh.mdx
sqlc把 .sql 编译成强类型 Go 函数的工具。make sqlc 重新生成。pkg/db/queries/ → pkg/db/generated/
Squad 小队一组 Agent 的集合，可整体作为被指派人，也可定义内部顺序。queries/squad.sql；squads.zh.mdx
Surface插件界面：宿主挂在固定位置的 iframe。可执行字节不放在主站源上。pkg/plugincontract/manifest.go
waiting_local_directoryRun 状态：目标本地目录被另一条在途运行占用，daemon 停车等待。仅 in_place 模式存在。pkg/protocol/events.go；troubleshooting
wakeup 唤醒Issue 级的触发规则：满足条件（含定时）时自动排一条 Run。queries/wakeup.sql；service/issue_wakeup*.go
Workspace 工作区租户与权限边界。所有查询按 workspace_id 过滤；X-Workspace-ID 选择它。AGENTS.md · Backend UUID Rules
X-Workspace-ID选择目标工作区的请求头。它只负责"选哪个"，能否进由成员资格决定。router.go；AGENTS.md

四个令牌前缀（背下来）

前缀代表范围
Cookie multica_auth浏览器里的你全量 Web API
mul_脚本里的你（PAT）与你的会话等同
mdt_你机器上的 daemon仅 /api/daemon/*
mat_某一次具体的 Run仅汇报那一条 Run
